# Mandala360 Browser — instaladores

Este repositório guarda **somente os instaladores** do Mandala360 Browser. O código-fonte é privado.

- **Baixar:** abra a aba [Releases](../../releases/latest) e escolha o arquivo do seu sistema:
  - Windows: `Mandala360-Browser-Setup-<versão>-x64.exe`
  - Mac com chip Apple (M1 em diante): `Mandala360-Browser-<versão>-arm64.dmg`
  - Mac Intel: `Mandala360-Browser-<versão>-x64.dmg`
- **Quem já tem o app instalado não precisa voltar aqui:** o próprio Mandala360 Browser avisa quando há versão nova e se atualiza com um clique.
- Baixe só daqui ou de quem a TI da Mandala360 indicar.
